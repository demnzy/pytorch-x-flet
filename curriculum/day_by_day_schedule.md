# PyTorch x Flet: 3-Day Intensive Curriculum

Welcome to the **PyTorch x Flet** Bootcamp! Over the next 3 days, you will learn the fundamentals of Python, build a complete Machine Learning pipeline using PyTorch (trainable directly in Google Colab), and connect it to a beautiful, modern UI using Flet. 

Each day is designed to take exactly **2 hours and 30 minutes (150 minutes)**.

## 🚀 The Curriculum

### Day 1: Setup, ML Intro & Python Basics (150 mins)
*Focus: Environment configuration, Machine Learning terminology, and Python fundamentals.*
- **Module 0: Software Setup & ML Intro (30 mins)** - Intro to Google Colab vs. Local Setup, and core ML terminology.
- **Module 1: Core Python Basics (30 mins)** - Variables, Data Types, and basic logic.
- **Module 2: Lists & Functions (30 mins)** - Grouping data and reusing code.
- **Module 3: Object-Oriented Programming (OOP) (40 mins)** - Classes, Objects, and Inheritance.
- **Module 4: The Python Ecosystem (20 mins)** - Installing and managing external packages.
- 🎯 **Day 1 Checkpoint Project**: *The Dummy Predictor*. Write a Python function that calculates a basic AQI score from scratch.

### Day 2: Data, PyTorch Model, & Intro to Flet (150 mins)
*Focus: Data manipulation with Pandas, building a Neural Network with PyTorch, and Flet basics.*
- **Module 5: Data Science & Pandas (40 mins)** - Understanding datasets and DataFrames.
- **Module 6: PyTorch & Training the Model (80 mins)** - Tensors, DataLoaders, Neural Architecture, and the Training Loop.
- **Module 7: Building Modern UIs with Flet (Part 1 - 30 mins)** - Flet fundamentals and basic layouts.
- 🎯 **Day 2 Checkpoint Project**: *The Brain Blueprint*. Load data in Pandas and build the PyTorch `AirQualityModel` class.

### Day 3: Full UI Build & Model Integration (150 mins)
*Focus: Advanced UI components, aesthetics, and linking the PyTorch `.pth` model to Flet.*
- **Module 7: Building Modern UIs with Flet (Part 2 - 60 mins)** - Advanced layouts, aesthetics, and Event Handlers.
- **Module 8: The Grand Integration (90 mins)** - Waking up the trained model inside the Flet app for real-time predictions.
- 🎯 **Day 3 Checkpoint Project**: *The Final Integration*. Train your final model, hook it into your beautifully styled Flet UI, and make live predictions.

---
**Note on Hardware Limitations:** 
If you do not have a powerful computer, **DO NOT WORRY**. The entire Machine Learning pipeline (Modules 1-6) can be executed natively in your browser using **Google Colab**. The Flet UI (Modules 7-8) is a fantastic bonus that you can run locally once your model is fully trained in the cloud!
